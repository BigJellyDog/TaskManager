Task Manager {VERSION} (Windows 10/11, 64-bit)

Start: double-click TaskManager.exe. No installation and no .NET needed.
The program files are in the "app" folder; keep it next to TaskManager.exe.

The app starts empty: Data -> "Fill with demo data" loads a set of sample tasks, and the same page
removes them again.

Windows SmartScreen may warn about an unsigned app: choose "More info" -> "Run anyway".

Your data (database, backups, exports, logs, settings) is kept in
%LOCALAPPDATA%\TaskManager
(the app shows the exact folder under Settings). To remove the app, delete the program folder and that data folder.

Source code and documentation (English and German):
https://github.com/BigJellyDog/TaskManager
